
## 三、本轮完成的最后功能

### 1. P4b MCP server

新增 `ai_service/mcp_server.py`，采用官方 MCP Python SDK v2，以 stdio 提供：

- `review_explain`：调用原审核 Agent，保留白名单工具、三重预算、转人工硬规则；
- `knowledge_ask`：调用原知识客服 Agent，保留越界闸门、接地闸门与无状态多轮历史。

安全边界没有因接入协议而变宽：审核字段在进入 Agent 前再次脱敏；客服返回采用字段白名单，
不对 MCP 调用方暴露 `trace`、`rejected_answer`、工具内部统计等审计信息；默认 stdio，
不额外开放一个缺少认证和限流的网络端口。

### 2. 补齐公开知识缺口

补充/调整了一二类账户差异、异地办卡、领卡时效、网点营业时间、转账限额五个场景。
所有易变化内容只给查询路径和通用规则，不编造固定营业时刻、具体时效或统一额度。

结果：对外 45 条合成威胁/边界问题集的语料未覆盖率从 **33.3% 降到 0.0%**，
同时保持安全方向指标不退化。

### 3. 验收基础设施修正

- CTE 在仓库外运行时不再把 Windows 盘符写入 `produced_asset`，审计记录可跨机器复用；
- pytest 每次生成独立临时根目录，避免历史残留目录 ACL 导致大量 fixture 假失败；
- 仓库根目录的旧 `.pytest-tmp-*` 会被测试发现阶段忽略。

## 四、项目亮点怎么讲

### 亮点 1：规则负责结论，AI 负责有限增强

平台没有把最终审核权直接交给模型。规则结论为 `reject` 时，AI 无权放行；模型不可用、
超时、输出非法或调用失败时，系统回落到规则原判。这比“接一个大模型生成解释”更接近
真实金融系统的安全边界。

### 亮点 2：测试 Agent 的过程，而不只测试一句答案

项目断言工具集合、参数、调用轨迹、预算消耗和停止原因，并用 cassette 录制回放真实模型
交互。CI 无需联网、无需 API key，也不会因模型随机性变成红绿灯抽奖。

### 亮点 3：两道客服安全闸门

个人信息、征信、个性化建议和内部口径在进入模型前就被出口闸门拦截；正常业务答复还必须
通过接地检查，没有知识引用就拒绝生成事实性回答。对外评估把“漏拒”“误拒”“知识缺口”
分开统计，能直接指向该修规则还是补语料。

### 亮点 4：CTE 把一次失败变成长期测试资产

真实失败先做不可覆盖的盲预测，再执行、比较、复盘、生成 Candidate、机器验证，最后必须
由人署名才能进入 `validated/`。系统可以孵化测试，但不能改 Ground Truth、降低门槛或
自行宣布通过，避免“系统给自己出题、自己改答案、自己打满分”。

### 亮点 5：评测输入从标注真值升级为真实 OCR 观测

评测不再把 `labels.json` 的正确字段偷偷当作系统输入，而是回放 2100 张图片的真实
PaddleOCR 输出。这一步暴露了 mock 拼接行为长期掩盖的跨行解析缺陷，也让“OCR 没认出”
和“解析器没取到”可以分别归因。

### 亮点 6：对局限保持可证伪的诚实

项目明确写出：合成数据不代表真实证件分布、真实模型样本量仍小、SQLite 不是生产级并发
存储、反光阈值需要产品口径。亮点不是声称系统已经生产可用，而是每个结论都有适用范围，
每个数字都能找到生成方式和失败条件。

## 五、演示建议

1. 从用户页提交一张合成银行卡，展示质量、OCR、字段、规则结论与 `request_id`；
2. 在管理端打开审核详情，展示落库记录与 AI Agent 轨迹；
3. 调用 MCP 的 `review_explain`，展示同一能力可被 Agent host 标准化接入；
4. 向 `knowledge_ask` 提问正常业务问题，再问“我征信上有什么问题”，对比正常引用答复与合规拒答；
5. 运行 `python -m scripts.run_cte --list`，展示真实失败如何进入长期资产；
6. 最后展示 `python -m pytest -q` 和两条评测命令的验收结果。

## 六、未关闭但不应擅自实现的边界

- `EVT-006` 标签误选已修复；模糊姓名准确率 55%，残余漏字/粘连仍需 OCR 改善；
- 反光严重度阈值：是否直接拒绝需要产品口径，不应只凭合成样本调参；
- `id_number` / `valid_period` 的低识别上限主要来自合成图水印遮挡，解析器无法恢复 OCR 未产生的字符；
- 真实证件与真实客户问题分布尚未纳入，当前指标只代表项目内合成集与录制快照。

这些项目保留为显式风险，不计为本轮工程验收失败。
