## 结论与限制

GPU 链路可以运行；单并发成功吞吐从此前 CPU 约 0.17 次/秒提高至本次 6.99 次/秒。增加并发到 4 后吞吐约 9.28 次/秒，8 并发未继续提高；当前共享 OCR 推理锁使推理串行，增加并发仍会增加排队。
本次没有出现 HTTP 错误或输出不一致。没有覆盖 GPU 40/80 并发或长时间稳定性，不代表此前 SQLite 高并发问题已修复。
服务日志存在实际依赖警告：Paddle 编译时 cuDNN 9.9，当前安装 cuDNN 9.5。该警告不能直接证明此前 CPU 异常退出的原因；GPU 短测通过也不能替代长期稳定性验证。
